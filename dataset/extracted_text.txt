Week 1 – Text Preprocessing 
Task Title 
Cleaning and Preparing Raw Text for Large Language Models 
Objective 
• The objective of this task is to introduce students to the first stage of every Natural Language 
Processing (NLP) and Large Language Model (LLM) pipeline—text preprocessing. 
• Students will learn how to convert raw, noisy text collected from websites, social media, PDFs, 
emails, and user conversations into clean, structured text that can later be tokenized, embedded, 
and processed by LLMs. 
• This cleaned dataset will be reused throughout the remaining weeks. 
Task Explanation 
Students will develop a Python program to preprocess raw textual data before it is used in a Large 
Language Model (LLM). The program should read text from a CSV or TXT file, remove punctuation, 
numbers, special characters, and extra spaces using regular expressions, convert all text to lowercase, and 
perform sentence and word tokenization using the NLTK library. Finally, the program should display and 
save the cleaned text for further processing.

Week 5 – Attention Mechanism 
Task Title 
Implementing and Visualizing Scaled Dot-Product Attention 
Objective 
• To understand the working principle of the Scaled Dot -Product Attention mechanism used in 
Transformer models.  
• To implement the attention mechanism from scratch using NumPy and PyTorch.  
• To visualize attention weights and understand how a model focuses on important words in a 
sentence.  
• To prepare for Prompt Engineering and advanced LLM concepts in the following weeks.  
Task Explanation 
The Attention Mechanism is the core component of Transformer-based Large Language Models. Instead 
of processing words one after another like traditional RNNs, Transformers use attention to determine 
which words in a sentence are most relevant to each other. 
In this task, students will manually implement the Scaled Dot-Product Attention algorithm. They will 
create Query (Q), Key (K), and Value (V) matrices, calculate attention scores, apply the Softmax function 
to obtain attention weights, and generate the final attention output. Students will also visualize the 
attention matrix to understand how the model distributes focus across different words. 
This activity helps students understand the internal working of Transformer models before using advanced 
LLM frameworks.

Week 12 – Semantic Document Search 
Task Title 
Building a Semantic Document Search System using LangChain and ChromaDB 
Objective 
• To understand the concept of semantic search using vector embeddings.  
• To retrieve relevant documents based on semantic similarity instead of keyword matching.  
• To integrate LangChain with ChromaDB for document retrieval.  
• To build a semantic search application that serves as the retrieval component of a Retrieval -
Augmented Generation (RAG) system.  
• To prepare the retrieved documents for LLM-based question answering in Week 13.  
Task Explanation 
Traditional search engines retrieve documents by matching keywords, which often produces irrelevant 
results when different words express the same meaning. Semantic Search overcomes this limitation by 
comparing the vector embeddings of documents and user queries. 
In this task, students will use the ChromaDB vector database created in Week 11 along with LangChain 
to build a semantic document search application. When a user enters a natural language query, the system 
will generate an embedding for the query, search the vector database, retrieve the most relevant documents, 
and display the results ranked by semantic similarity. 
This retrieval system will be extended into a PDF Question Answering (RAG) application in Week 13.

Week 13 – PDF Question Answering 
Task Title 
Building a PDF Question Answering System using LangChain, ChromaDB, and Ollama 
Objective 
• To understand the concept of Retrieval-Augmented Generation (RAG).  
• To extract text from PDF documents and convert it into vector embeddings.  
• To retrieve relevant information from PDF documents using ChromaDB.  
• To generate context-aware answers using a local Large Language Model (LLM) through Ollama.  
• To prepare the backend for a web-based LLM application in Week 14.  
Task Explanation 
Organizations often store information in PDF documents such as manuals, policies, reports, and research 
papers. Instead of manually reading these documents, a Retrieval-Augmented Generation (RAG)  
system enables users to ask questions in natural language and receive accurate answers based on the 
document content. 
In this task, students will build a PDF Question Answering System. They will extract text from a PDF 
file, split the text into smaller chunks, generate embeddings, store them in ChromaDB , retrieve the most 
relevant chunks for a user query, and use Ollama with a local LLM to generate answers based only on the 
retrieved content.
